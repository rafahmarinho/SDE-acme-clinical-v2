Quero desenvolver esta aplicação, com aparência e funcionamento próximos de um produto real.

Use inglês como idioma padrão em todas as telas, mensagens, relatórios e dados de exemplo.

Use versões atuais e estáveis das tecnologias e Supabase para PostgreSQL, login por e-mail e

senha, arquivos e atualizações em tempo real. Quero as telas funcionando e os dados

persistidos, com integrações externas simuladas. Organize o projeto em telas, componentes,

serviços e acesso ao banco. Inclua login, recuperação de senha, perfil, configurações, busca,

filtros, estados de carregamento e mensagens de erro. Adapte a navegação aos perfis de

usuário.

O sistema médico vai se chamar ACME Clinical. Use Python com FastAPI e Pydantic no backend e

React com Vite e TypeScript no frontend, publicados separadamente na Vercel. Use pnpm no

frontend. A geração das leituras, os alarmes e os relatórios devem ser feitos em Python. A

interface deve ser clara, com fundo branco, texto azul-marinho e números grandes. Crie uma

visão por ala, lista e detalhe de pacientes, monitoramento ao vivo, alarmes, dispositivos,

configurações de limites, relatórios e gestão da equipe (pode criar algo bem visual em 3D se

conseguir para simular as ações). Use pacientes fictícios e monitores simulados para mostrar

frequência cardíaca, saturação, respiração, pressão arterial e um traçado sintético de ECG.

Permita vincular um monitor a um leito, registrar observações, reconhecer alarmes e

acompanhar manutenção. Reconhecer um alarme não encerra uma condição que ainda está

acontecendo. Simule leituras normais, saturação baixa, bateria fraca, problema no sensor e

perda de conexão. Tenha perfis de enfermeiro, médico, técnico biomédico e administrador.

Prepare dados de demonstração com doze pacientes e dez monitores. Inclua uma área para

escolher cenários, avançar a simulação, consultar eventos e reiniciar os dados. Os resultados

devem aparecer nas telas e continuar salvos após recarregar a aplicação. Entregue o código

completo, configuração do banco, dados iniciais, exemplos de variáveis de ambiente e um

README com os passos para rodar e publicar a versão web e a API na Vercel. Confira os fluxos

principais, mantenha a implementação objetiva e conclua as páginas e ações descritas.
